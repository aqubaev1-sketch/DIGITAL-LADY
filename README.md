# Digital Lady Technopark — Next.js site

High-fidelity local reconstruction of `https://summit.roboflow.com/`, created from runtime and shipped-artifact evidence gathered with REA.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

For a production check:

```bash
npm run build
npm run start
```

## Included

- Complete responsive landing page: hero, narrative reel, intro, event overview, agenda, speakers, time/place, animated ticket, FAQ, and footer.
- Local copies of the publicly served images, videos, SVG artwork, icons, and web fonts used by the reference page.
- Responsive desktop and mobile layouts.
- Video controls, fullscreen playback, sticky navigation, accordion interaction, hover effects, attendee/logo marquees, speaker reveal effects, custom cursor, and animated 3D ticket.

The registration and Roboflow buttons intentionally retain their original external destinations. Runtime media and font requests are otherwise local.
